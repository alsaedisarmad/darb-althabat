# دربُ الثبات · تفسير سورة هود (١١٢–١٢٣)

درس تفاعلي لمادة **القرآن الكريم وتفسيره**، الوحدة الرابعة، الدرس العاشر.

- **إعداد معلمة المادة:** أ. فاطمة الطلحي
- **مديرة المدرسة:** أ. آمال باربود

## تشغيل الدرس
- **عبر الإنترنت:** افتحي رابط GitHub Pages الخاص بالمستودع.
- **بدون إنترنت:** نزّلي ملف `index.html` وافتحيه في Chrome أو Edge. الخطوط والتلاوة والفيديو كلها مدمجة داخل الملف.

## محتوى الدرس
٢٢ محطة موزعة على خمسة فصول: تهيئة، نتلو ونفهم، نتدبر، نطبّق، نختم. من أبرزها:
- مصحف تفاعلي بثلاث عدسات (الأوامر والنواهي، المفردات، الإخفاء) مع المعنى الإجمالي لكل آية.
- بطاقات كشط للمفردات، وقصة سبب النزول في أربعة مشاهد.
- لعبة ميزان الاستقامة، ومحاكاة حديث النهر، وقرية المصلحين.
- فرز وترتيب وربط وصيد مواضع الإخفاء، وتقويم ختامي، وبطاقة خروج قابلة للطباعة.
- لوحة للمعلمة فيها: نقاط الفرق، ومؤقت، واختيار طالبة عشوائيًا، وخطة الحصة.

**اختصارات لوحة المفاتيح:** الأسهم للتنقل · `T` المؤقت · `R` اختيار طالبة · `F` ملء الشاشة.

## هيكل المستودع
```
index.html        الدرس الجاهز (ملف واحد، يُبنى تلقائيًا)
src/lesson.html   القالب الذي يُعدَّل
assets/           شعار الوزارة، الفيديو، التلاوة
fonts/            الخطوط وتراخيصها (SIL OFL)
build.py          يدمج الملفات في index.html
```

## التعديل
عدّلي `src/lesson.html` ثم شغّلي:
```
python build.py
```
